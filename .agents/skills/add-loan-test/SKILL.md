#
Добавление автотеста loan app
-

Сначала изучи запрошенный сценарий, конфигурацию Playwright и существующие тесты. 
Уточни ожидаемое поведение по контракту или исходному коду, если его нельзя установить, спроси, а не придумывай.

Используй структуру проекта tests/pages для страниц, tests/components для элементов. Переиспользуй существующие методы и локаторы, новые добавляй лишь при необходимости. Сохраняй стиль проекта и не меняй написанные сценарии. 

Для каждого сценария проверяй поведение интерфейса. Необходимо ожидать нужный ответ до действия, которое отправляет запрос. После
завершения запроса проверяй состояние UI.

Для сетевых сценариев проверь адрес и параметры запроса. Установи page.route до действия, вызывающего запрос, и подготовь ответ согласно контракту.
Инструкции для теста с моком: найти запрос и контракт, зарегистрировать
перехват до запроса, подготовить ответ, проверить UI и запустить тест. Не придумывай
локаторы и ожидаемое поведение.

Запусти новый тест и сообщи команду и результат. Просмотри изменения, явно сообщи, что не удалось проверить.
